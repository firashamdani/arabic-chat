# 💬 شات العرب — نظام محادثة عربي متكامل

شات عربي كامل للغرف والمحادثات الخاصة، بواجهة مكتبية RTL، مع لوحة تحكم أدمن شاملة.
يعمل على **Vercel (مجاني) + MongoDB Atlas (مجاني) + Pusher (مجاني) + Cloudinary (مجاني)**.

---

## ✨ الميزات

### للأعضاء
- 🔐 **تسجيل ودخول** بحسابات آمنة (bcrypt + JWT، جلسة 7 أيام)
- 🚪 **غرف عامة** — 6 غرف جاهزة + إنشاء غرف جديدة من أي عضو
- 🔒 **محادثات خاصة** (DM) مع أي عضو
- 📷 **رفع صور وملفات وفيديو وصوت** (Cloudinary) + لصق صورة مباشرة بـ Ctrl+V
- ↩️ **الرد على الرسائل**، ✏️ **التعديل**، 🗑 **الحذف**
- 💬 **مؤشر "يكتب الآن…"** لحظياً
- 👥 **قائمة المتصلين الآن** + آخر ظهور + نبذة تعريفية
- 📣 **@منشن** مع إشعار فوري
- 🔔 **إشعارات سطح المكتب** + صوت تنبيه
- 🔢 **عداد الرسائل غير المقروءة** لكل غرفة
- 😊 **لوحة إيموجي**
- 🌙 **وضع ليلي/نهاري** + بحث فوري في الغرف والأعضاء
- 📱 **متجاوب** مع الجوال والحاسوب

### للأدمن (`/admin`)
- 📊 **لوحة مؤشرات**: أعضاء، رسائل، غرف، متصلون الآن، موقوفون
- 📈 **مخططات**: نشاط 7 أيام، أنشط الغرف، أنشط الأعضاء، توزيع الأدوار
- 👥 **إدارة الأعضاء**: ترقية (عضو/مشرف/أدمن)، إيقاف مؤقت/دائم مع سبب، رفع إيقاف، إعادة تعيين كلمة المرور، حذف نهائي
- 🚪 **إدارة الغرف**: قفل/فتح، تثبيت، حذف مع كل رسائلها
- 💬 **إشراف على الرسائل**: بحث في كل الرسائل وحذف أي رسالة
- ⚙️ **إعدادات الموقع**: الاسم، الشعار، إعلان عام، رسالة ترحيب، فتح/إغلاق التسجيل، وضع الصيانة

## 🚀 التشغيل المحلي

```bash
npm install
cp .env.example .env      # ثم عدّل MONGODB_URI و JWT_SECRET
npm start                 # http://localhost:3000
```

عند أول تشغيل يُنشئ المشروع تلقائياً:
- حساب الأدمن (`ADMIN_USERNAME` / `ADMIN_PASSWORD`)
- 6 غرف عامة جاهزة + رسالة ترحيب

## 🧪 الاختبار

```bash
npm test        # يشغّل MongoDB في الذاكرة + الخادم + 65 اختباراً على كل المسارات
```

## ☁️ النشر المجاني

الخطوات التفصيلية بالصور والشرح في **[DEPLOY.md](./DEPLOY.md)**.

| الخدمة | الاستخدام | الخطة المجانية |
|---|---|---|
| **Vercel** | استضافة الموقع + الـ API | 100 جيجابايت/شهر |
| **MongoDB Atlas** | قاعدة البيانات | 512 ميجابايت |
| **Pusher Channels** | البث اللحظي للرسائل | 200 ألف رسالة/يوم |
| **Cloudinary** | تخزين الصور والملفات | 25 وحدة/شهر |

> **لماذا Pusher؟** خطة Vercel المجانية (Serverless) لا تدعم اتصالات WebSocket طويلة الأمد.
> Pusher يوفّر طبقة Realtime مجانية كاملة، والتطبيق ينتقل إليها تلقائياً.
> وإن تعذّر الاتصال، يعمل التطبيق تلقائياً على **تحديث تلقائي كل 5 ثوانٍ** دون انقطاع الخدمة.

## 🔌 أهم مسارات الـ API

| المسار | الوصف |
|---|---|
| `POST /api/auth/register` `/login` `/logout` | الحسابات |
| `GET/PATCH /api/auth/me` | الملف الشخصي |
| `GET/POST /api/rooms` · `GET/PATCH/DELETE /api/rooms/:id` | الغرف |
| `GET/POST /api/messages` · `PATCH/DELETE /api/messages/:id` | الرسائل |
| `POST /api/users/:id/dm` | فتح محادثة خاصة |
| `GET /api/users` `/online` · `POST /api/users/ping` | الأعضاء والحضور |
| `POST /api/pusher/auth` | تفويض قنوات البث اللحظي |
| `/api/admin/*` | لوحة الأدمن (stats, users, rooms, messages, settings) |
| `GET /api/health` `/api/bootstrap` | الفحص والإقلاع |

## 🔐 الأمان

- كلمات المرور مُشفّرة بـ **bcrypt** (cost 10)، ولا تُخزَّن أبداً كنص
- **JWT** بصلاحية 7 أيام، وكل مسار محمي يفك التشفير من قاعدة البيانات (لا يثق بالتوكن وحده)
- فحص الصلاحيات **في الخادم** على كل عملية (منشن، حذف، قفل غرفة، دخول غرفة خاصة)
- **express-rate-limit**: 300 طلب/دقيقة عام، 40 محاولة دخول/15 دقيقة
- منع **NoSQL injection** عبر تحويل كل المدخلات إلى نصوص
- كل النصوص المعروضة تُهرَّب من HTML (لا XSS)
