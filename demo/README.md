# 📄 رفع العرض التجريبي على GitHub Pages

هذا ملف **واحد مستقل** (`index.html`) — لا يحتاج خادماً ولا حزم.
يعرض واجهة شات العرب كاملة وتعمل فعلاً داخل المتصفح.

---

## ⚡ الطريقة الأسرع (5 دقائق)

1. افتح مستودعك: **https://github.com/firashamdani/arabic-chat**
   (إن لم يكن موجوداً: **New repository** ← اسمه `arabic-chat` ← **Create**)

2. اضغط **Add file → Upload files**

3. اسحب ملف **`index.html`** فقط → **Commit changes**

4. اذهب إلى **Settings → Pages** (أنت فيها الآن):
   - **Source**: `Deploy from a branch`
   - **Branch**: `main` · المجلد: `/ (root)` ← **Save**

5. انتظر **1–3 دقائق**، ثم افتح:
   ```
   https://firashamdani.github.io/arabic-chat/
   ```

6. فعّل **Enforce HTTPS** (مفعّل تلقائياً على `github.io`).

> 💡 إن لم يظهر الموقع بعد 3 دقائق، افتح **Actions** في المستودع — يجب أن ترى
> workflow باسم `pages build and deployment` بلون أخضر ✅

---

## ⚠️ الطريقة الثانية: رفعه في مجلد `docs/`

إن كان المستودع يحتوي المشروع الكامل (مجلد `server/` و`public/` …):

1. ارفع `index.html` داخل مجلد اسمه **`docs`** ← يصبح `docs/index.html`
2. في **Settings → Pages** اختر **Branch: `main`** · المجلد: **`/docs`** ← **Save**
3. الرابط يبقى: `https://firashamdani.github.io/arabic-chat/`
